# Regra — Laboratórios e Código

- Preservar arquivos originais.
- Usar ambientes isolados quando aplicável.
- Registrar dependências.
- Não instalar ou remover software sem autorização.
- Não usar credenciais em código.
- Criar README para laboratórios relevantes.
- Explicar como reproduzir.
- Preferir código simples, testável e observável.
- Executar testes quando possível.
- Nunca afirmar que algo executou com sucesso sem evidência.
