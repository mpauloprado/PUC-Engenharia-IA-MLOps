# Preparação para prova

Use `$ARGUMENTS` para indicar disciplina, unidades e data se conhecida.

1. Levante material efetivamente estudado.
2. Separe conteúdo confirmado de tópicos apenas relacionados.
3. Monte matriz:
   - tópico;
   - fonte;
   - importância;
   - domínio atual;
   - ação de revisão.
4. Gere perguntas inéditas apenas do escopo confirmado.
5. Misture recordação, aplicação e troubleshooting quando coerente.
6. Após respostas, explique os erros e atualize a lista de lacunas.
7. Nunca afirme conhecer questões futuras.
