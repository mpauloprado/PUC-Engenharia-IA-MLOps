# Revisão semanal

1. Leia `00_ADMIN/PROGRESSO_GERAL.md`.
2. Leia `00_ADMIN/PENDENCIAS.md`.
3. Verifique materiais adicionados recentemente.
4. Liste avanços com evidência.
5. Liste pendências críticas.
6. Identifique lacunas recorrentes.
7. Proponha plano enxuto para a próxima semana.
8. Não invente datas ou prazos ausentes.
