# Fontes para baixar — PUC Minas

## 1. Canvas — fonte principal dos materiais das disciplinas
Link oficial:
https://pucminas.instructure.com/

Caminho recomendado:
1. Entrar no Canvas.
2. Abrir `Cursos`.
3. Selecionar a disciplina.
4. Verificar `Arquivos`, `Módulos`, `Página inicial`, `Tarefas/Atividades`, `Avisos` e `Gravações/Teams`, quando existirem.
5. Baixar os arquivos originais e colocar em:
   `disciplinas/<disciplina>/00_original/`

Para Pipeline de Dados, a estrutura já observada no Canvas contém:
- Aula 1 — Arquiteturas e fundamentos de pipelines de dados
- Unidade 1
- Unidade 2
- Unidade 3
- Unidade 4
- Layout

Baixar o conteúdo interno dessas pastas antes de iniciar resumos.

Situação em 16/09/2026: a Aula 1 foi baixada (apresentação e Exercício 1). As pastas
Unidade 1 a 4 e Layout contêm apenas assets do Canvas; verificar também Módulos,
Páginas e Tarefas. Ver `disciplinas/01_pipeline_dados/01_aulas/INVENTARIO_00_ORIGINAL.md`.

## 8. Documentos de cada disciplina — checklist
Para cada disciplina, procurar e baixar quando disponível:
- plano de ensino;
- ementa;
- cronograma;
- slides;
- PDFs;
- leituras obrigatórias;
- notebooks;
- scripts;
- datasets;
- templates;
- enunciados;
- rubricas;
- exemplos;
- gravações ou transcrições autorizadas;
- feedbacks do professor;
- avisos com alteração de prazo ou escopo.

## Regra de preservação
Todo arquivo baixado da PUC deve entrar primeiro em `00_original/`.
Nunca editar o original.
